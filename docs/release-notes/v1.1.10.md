RPCEmu (Spork Edition) 1.1.10 collects a batch of correctness and platform fixes, and packages macOS as a proper application.

## Highlights

- **Correct FPA10 floating point.** The floating-point coprocessor emulation has been rewritten around true extended-precision registers, fixing corrupt numbers in BASIC and C floating-point output. This affects every platform.
- **Configuration is no longer lost.** Changing a machine's memory size no longer resets `cmos.ram`, and new machines default to HostFS so they boot straight to the desktop.
- **macOS is now a real app.** The macOS download is a universal `RPCEmu.app` inside a drag-to-Applications `.dmg`, with its own icon and menu-bar identity. Writable data lives in `~/RPCEmu`, so the app in `/Applications` stays read-only. See the note on first launch below.

## Fixes by platform

**All platforms**
- FPA10 floating-point correctness rewrite (#27).
- CMOS configuration preserved across memory-size changes; default to HostFS (#28).
- VNC: corrected mouse button mapping and added scroll-wheel support (#34).
- ROM-patching suspend/resume fix, and more graceful shutdown on error, thanks to @mesham (#32, #33).

**macOS**
- Packaged as a universal `RPCEmu.app` in a `.dmg` (icon, `Info.plist`, ad-hoc signed).
- Fixed an unresponsive keyboard (#29).
- Fixed Ctrl-key combinations (#35).
- The arm64 recompiler now runs under the hardened runtime via `MAP_JIT` (#30); arm64 release builds still ship the interpreter for now.

**Windows**
- Raised the timer resolution so "Reduce CPU Usage" is no longer laggy (#26).

## Known issues

- **arm64 Linux / Raspberry Pi recompiler (#30):** when built as the recompiler, the display can stay blank while the CPU runs. Under active investigation; released arm64 builds ship the interpreter and are unaffected. A diagnostic switch (`RPCEMU_ARM64_ICACHE_PARANOID`) has been added to help pin this down on real hardware.

Several of the platform fixes above are reasoned from the reported behaviour and confirmed to build, but have not yet been re-tested by the original reporters. Feedback on this release is very welcome.

## First launch on macOS

The app is signed but not notarised by Apple, so the first launch is blocked with a "cannot be opened" warning. To open it the first time only: right-click (or Control-click) the app, choose Open, then Open again. macOS remembers the choice afterwards. On Sequoia and later, use System Settings > Privacy & Security > Open Anyway if the Open option is not offered.
