## RPCEmu – Spork Edition 1.1.8

### New

- **Kinetic StrongARM (512MB)** — a new machine model emulating the Acorn Risc PC **Kinetic** StrongARM processor card with its full **512MB** of RAM: the 256MB the motherboard IOMD can address, plus two 128MB on-card SDRAM banks. Boots RISC OS 5 straight to the desktop. Select *Kinetic StrongARM (512MB)* in the machine editor. (Closes #11.)
- **macOS support** — a **universal** build (Intel + Apple Silicon), joining Linux and Windows. The Intel slice runs the dynamic recompiler, the Apple Silicon slice uses the interpreter, and the two are fused with `lipo`. Ships as `rpcemu_1.1.8_macos_universal.tar.gz`.
- **16MB VRAM option** for the Risc PC.

### Fixed

- **Machine reset no longer crashes the emulator.** A stale physical-TLB-invalidate entry left after a CP15 reset could trigger an out-of-bounds write; reset now re-boots cleanly. (Affects all models.)
- **HostFS:** `Boot$Dir` is defined at module init, so host→guest drag-copy works without a `!Boot` present (#17).
- **Machine Inspector:** text selection is preserved across auto-refresh (#13).
- Additional robustness/hardening across the memory, sound, IDE and IOMD paths.
