## RPCEmu (Spork Edition) 1.1.9

### New features
- **Save / load state, suspend & resume** — snapshot a machine's complete running state (CPU, RAM, VRAM, devices and networking) to disk and restore it exactly. *File → Save State* / *Load State* for named snapshots, or *File → Suspend* to save-and-exit and pick up later via the machine's **Resume** button in the selector. Contributed by **Nick Brown**.
- **High-resolution display support** — automatic monitor detection via EDID and fit-to-window scaling, with related full-screen and mouse fixes.
- **Kinetic VRAM handling and ROM-patch consolidation** — ROM patching moved into `rom_patch.c`, with power-off support and improved Kinetic VRAM handling; suspend is now opt-in.
- **Machine editor constraints** — the machine editor now offers only the RAM/VRAM combinations each model actually supports, so you can't pick a configuration that won't boot.

### Fixes
- **Wrong colours in MCP/VNC screenshots** — corrected the pixel format so captures come through with the right colours (#23).
- **Windows: mouse button could stick when released outside the emulator window** — the pointer is now captured for the duration of a drag, keeping RISC OS in step (#25).
- **HostFS activity starved mouse/keyboard input, and audio lagged behind** — HostFS path lookups no longer stat every directory entry, and the audio back-pressure was fixed so latency no longer ratchets up (#24).
- **Access/ShareFS** — stopped double-sending unicasts in NAT mode.

### Under the hood
- **Native arm64 (AArch64) recompiler backend** — a full AArch64 code generator at parity with the x86 backends, validated under emulation. Prebuilt **arm64 releases still ship the interpreter** for now, pending testing on real arm64 hardware.
- Documentation restructured into proper reference material.
- Source attribution and GPL licence headers tidied up, including crediting **Arculator** (Sarah Walker) for the podule subsystem.
